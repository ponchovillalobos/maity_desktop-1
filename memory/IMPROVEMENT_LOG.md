# Improvement Log — Maity Desktop

Append-only. Cada entrada documenta un ciclo de `/improve` o `/improve-pr` exitoso.

## Formato

```
### YYYY-MM-DD — Iter #N — <EXP-ID>
- **Experto:** <expert>
- **Título:** <title>
- **Branch / PR:** <branch> / <PR url>
- **Archivos:** <list>
- **Tests:** <antes> → <después>
- **Clippy warnings:** <antes> → <después>
- **Notas:** <opcional>
```
